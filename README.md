-- 🔐 VAULT — خزنة كلمات المرور الآمنة

تطبيق سطح مكتب لإدارة كلمات المرور بتشفير عسكري المستوى، مبني بـ Python + Tkinter.

---
-- ✨ المميزات

-- الأمان
- تشفير AES-256-GCM لكل البيانات
- اشتقاق المفاتيح بـ ""Scrypt"" (N=131072) + "HKDF" + "HMAC-SHA256"
- حماية Brute-Force بتأخير تصاعدي (2 ← 4 ← 8 ← 16 ← 30 ثانية)
- مسح تلقائي للحافظة بعد 30 ثانية مع عداد مرئي
- قفل تلقائي للجلسة بعد فترة خمول قابلة للضبط
- قفل فوري عند تصغير النافذة
- نسخ احتياطية مشفرة تلقائية عند كل حفظ
- سجل نشاط أمني مشفر
- التحقق من تكامل الملف عند كل فتح

-- إدارة الحسابات
- إضافة، تعديل، حذف الحسابات
- عرض قوة كلمة المرور (ضعيف / متوسط / قوي / ممتاز)
- تنبيه الكلمات المرور الضعيفة والمكررة
- فرز الأعمدة بالضغط على العنوان
- بحث فوري في الحسابات
- نسخ كلمة المرور بنقرة واحدة

-- استيراد / تصدير
- استيراد CSV من "Chrome" و "Firefox" مباشرة
- تصدير CSV متوافق مع Chrome/Firefox
- دعم فتح وإدارة "أكثر من خزنة" بملفات منفصلة

-- واجهة المستخدم
- دعم كامل للغة "العربية" و "الإنجليزية"
- وضع "فاتح" ووضع "داكن"
- تبويبات: الحسابات — تحليل الأمان — الإعدادات — السجل

تُحفظ كل بيانات التطبيق في:

```

├── vault.dat              ← الخزنة المشفرة
├── vault_settings.json    ← إعدادات التطبيق
```

-- 🔐 تفاصيل التشفير

```
كلمة المرور
    ↓
Scrypt (N=131072, r=8, p=1) + Salt عشوائي 32 بايت
    ↓
Master Key (32 بايت)
    ↓
HKDF-SHA256
    ↙           ↘
Enc Key      HMAC Key
    ↓
AES-256-GCM + Nonce عشوائي 12 بايت
    ↓
بيانات مشفرة + HMAC-SHA256 للتحقق
```

لا يوجد أي مفتاح ثابت في الكود — كل شيء مشتق من كلمة مرور المستخدم.
